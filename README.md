# Gudino_martes3 - Club de Lectura "Página en Blanco"

## ¿De qué se trata la web?
Este sitio web es una página informativa sobre un club de lectura local. Su objetivo es compartir las lecturas recomendadas del mes, los horarios de las reuniones presenciales y un formulario sencillo para que nuevos integrantes se unan a la comunidad.

## Herramientas utilizadas
* **HTML5:** Para la estructura general del sitio (títulos, párrafos y listas).
* **CSS3:** Para aplicar estilos visuales como colores, fuentes y márgenes.
* **Visual Studio Code:** Como editor de código principal.
* **Git & GitHub:** Para guardar el historial de cambios y alojar el repositorio.
